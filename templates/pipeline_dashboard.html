      Connection check

      The check reads permissions and product access without uploading images or creating a listing.

      Connect your store

      1. WooCommerce products

        In WooCommerce settings, open Advanced and REST API. Create a Read/Write key and use it with your HTTPS store address in .env.

      2. WordPress media

        In WordPress Users, open Profile and create an Application Password. Use that user's login for WORDPRESS_MEDIA_USER and the generated password for WORDPRESS_MEDIA_APP_PASSWORD.

      3. Restart and test

        Save .env, restart Django and run the connection check.

      Account check

      Set up in .env

      Meta app requires META_APP_ID, META_APP_SECRET and META_GRAPH_API_VERSION.

      Facebook requires FACEBOOK_PAGE_ID and FACEBOOK_PAGE_ACCESS_TOKEN.

      Instagram can use the professional account linked to that Page. If you use Instagram Login, set INSTAGRAM_ACCOUNT_ID and INSTAGRAM_ACCESS_TOKEN instead.

      TikTok requires TIKTOK_ACCESS_TOKEN with upload access and TIKTOK_MEDIA_BASE_URL with a verified HTTPS media prefix. Finish the draft from your TikTok inbox.

      Reload Django after saving your settings.
